# warden — MAD agent runtime monitor

Живой монитор рантайма агента. Читает поток событий `{id, input, output}` (JSONL) и на каждое
событие применяет детекторы: **канарейка из входа, всплывшая в выходе без отказа = исполнение
скрытой инструкции**. Выполнение ≠ цитата (канарейка внутри отказа «I will not output …» —
защита, не провал).

```
warden watch <events.jsonl> [--json report.json]
```

Коды возврата: `0` чисто · `1` найдено исполнение · `2` файл пуст/битый/нет (не состоялась).

Находки идут в общую БД `finding-organizer` (`ingest_tool_report`); если она недоступна —
в `--json`. Вердикт ставит код, ноль обращений к языковой модели.
